Graphic design

Advertising poster

Voyages Estrange, agency specializing in selling travel to unusual locations, wanted an advertising poster for its branch to promote three locations. The project was created using Affinity Designer software. Furthermore, the photos used for the project were sourced from a royalty-free image library.

Voyages Estrange is a fictional company. The logo and graphic elements were designed and created by J.Cloutier.

Restaurant menu

Starship Burger wanted a printed menu reflecting its space theme, for distribution by mail and in its restaurants. The project was created using Affinity Designer software. Furthermore, the photos used for the project were sourced from a royalty-free image library, some of which were modified using Affinity Photo software.

Starship Burger is a fictional company. The logo and graphic elements were designed and created by J.Cloutier.

Interactive kiosk

In addition to a printed menu, Starship Burger has added interactive kiosks to its restaurants, allowing customers to order their meal independently. The project was created using Affinity Designer software. Furthermore, the photos used for the project were sourced from a royalty-free image library, and some were modified using Affinity Photo software.

Starship Burger is a fictional company. The logo and graphic elements were designed and created by J.Cloutier.
